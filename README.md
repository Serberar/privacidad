# Política de privacidad

Página estática con la política de privacidad de mis aplicaciones. Está publicada con GitHub Pages para poder enlazarla desde las fichas de las apps y desde los formularios que recogen datos.

**Ver online:** https://serberar.github.io/privacidad/

## Qué incluye

1. Responsable del tratamiento.
2. Datos que se recopilan (solo los necesarios para contactar y prestar el servicio).
3. Uso de los datos.
4. Conservación.
5. Compartición de datos.
6. Seguridad.
7. Derechos del usuario.
8. Cambios en esta política.
9. Contacto.

## Cómo actualizarla

Edita `index.html` y haz push a `main`: GitHub Pages publica el cambio en uno o dos minutos.
